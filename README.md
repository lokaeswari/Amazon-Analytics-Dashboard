 Spotify Analytics Dashboard (Power BI Project)

Project Summary

This project presents an interactive Spotify Analytics Dashboard developed using Power BI.  
The dashboard analyzes Spotify song data to uncover insights related to artist performance, song popularity, album types, and monthly trends.

The goal of this project is to transform raw music streaming data into meaningful business insights using data visualization and analytics techniques.

 Business Questions Answered

- Which artists have the highest number of top-performing songs?
- What audio features contribute most to song popularity?
- How does song popularity vary across months?
- How do explicit songs compare with non-explicit songs in terms of performance?
- Which album types generate the highest popularity?

 Tools & Technologies Used

- **Power BI Desktop** – Dashboard creation and visualization  
- **Power Query** – Data cleaning and transformation  
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs  
- **CSV Dataset** – Spotify Top Songs data  

 Project Implementation

- Imported and cleaned the dataset using Power Query  
- Created calculated measures and KPI indicators using DAX  
- Designed interactive visualizations and charts  
- Developed multiple dashboard pages for structured analysis  
- Implemented filters and slicers to explore trends dynamically  

Dataset Information

The project uses a dataset of Spotify Top Songs containing:

- Track Name  
- Artist Name  
- Popularity Score  
- Album Type  
- Explicit Indicator  
- Audio Features (Danceability, Energy, Tempo, etc.)  
- Release Date / Monthly Data
